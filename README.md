### [Mon Orientation Supérieure]

🇫🇷 Plateforme web qui met en relation des lycéens et des étudiants pour partager des retours d'expérience concrets sur l'orientation post-bac.

🇬🇧 Web platform connecting high school students with university students to share real-life experiences about post-secondary education choices.

-  **Live site / Site en ligne :** [mon-orientation-superieure.vercel.app](https://mon-orientation-superieure.vercel.app)
-  **Stack :** HTML / CSS / JavaScript · Supabase (PostgreSQL, Auth, Storage, Edge Functions) · Resend · Vercel
-  **Fonctionnalités :** authentification, profils, recherche, messagerie, notifications, espace d'administration
